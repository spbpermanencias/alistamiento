# Alistamiento – Chequeador (PWA)

1. Sube TODO el contenido de esta carpeta a la raíz de un repo público en GitHub (incluye `.nojekyll` y la carpeta `icons/`).
2. Settings → Pages → Branch `main` → `/ (root)` → Save.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-REPO/` en el celular:
   - Android (Chrome): menú ⋮ → Instalar aplicación.
   - iPhone (Safari): Compartir → Añadir a pantalla de inicio.
4. Entra con usuario y clave del sistema (rol con permiso de Chequeador).

Usa el mismo proyecto Supabase de permanencias.html. Si cambias de proyecto, edita SB_URL y SB_KEY en index.html.
